说明：本游戏是 Windows 桌面客户端，不能在本网页里直接下棋。 请下载客户端后双击运行（已默认连接下方服务器）。
公网服务器：140.143.202.203　端口：9527

开始游戏（Windows）

  1. 下载并解压发布包 gobang_client.zip（由作者提供）
  2. 双击文件夹内的 开始游戏.bat 或 GobangClient.exe
  3. 注册账号 → 登录 → 大厅匹配或人机对战

下载 Windows 客户端（zip）

若下载链接无效，请向作者索取 release 文件夹压缩包。 部署者：将 web/landing 放到 Nginx，并把打包好的 zip 放到同站可下载路径。

服务器部署检查（管理员）

  1. 云服务器运行 run_server.bat，监听 0.0.0.0:9527
  2. 安全组入站放行 TCP 9527
  3. Windows 防火墙入站规则放行 9527（如适用）
