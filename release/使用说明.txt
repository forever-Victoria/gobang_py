网络五子棋 - 玩家使用说明
================================

【重要】本游戏是 Windows 桌面程序，不能像网页那样在浏览器里直接打开下棋。
请双击「开始游戏.bat」或「GobangClient.exe」启动。

一、首次使用
1. 解压整个文件夹（不要只复制 exe，需要保留 config 目录）
2. 双击「开始游戏.bat」
3. 登录页已预填公网服务器，一般无需改地址
4. 输入用户名、密码 → 点「注册」→ 再点「登录」
5. 大厅可「开始匹配」或「人机对战」

二、默认服务器
  地址：140.143.202.203
  端口：9527

若连不上，请确认：
- 本机已联网
- 云服务器安全组/防火墙已放行 TCP 9527
- 服务器上 run_server.bat 正在运行

三、修改服务器（可选）
  编辑 config\online.json 中的 host 和 port，保存后重新打开客户端。

四、系统要求
  Windows 10/11，无需安装 Python（已打包进 exe）。
